# チュートリアル

## 開始

- `Assets/Scenes/main/Tutorial.unity` を開いて再生するか、StartシーンのTutorialボタンを押します。
- TutorialシーンはBuild Settingsへ登録済みです。
- TutorialManagerの参照未設定時は、同じシーンのplayerDevice、system_event、各Spawnerを自動検索します。
- 説明と進捗UIは実行時に生成されます。「はじめる / 次へ」またはEnterで説明を閉じます。
- 説明パネルはタイマーより下の画面中央付近（高さ38〜63%）に表示します。
- キーボードのレーン移動は既存Moveアクションを使用し、キーを離すと中央へ戻ります。センサーのint入力も維持しています。
- 最後の説明を進めるとInGameシーンを読み込み、ゲームを開始します。onCompletedはシーン切替直前の通知用です（別のシーン切替は登録しないでください）。

## 条件

1. 成立したジャンプ3回。フライパンとパンケーキ本体の上下接触で着地を確認するまで再ジャンプできません。コンロ・アイテム・落下デコレーションとの接触ではジャンプを解禁しません。開始直後も接地を待ちます。
2. 左・中・右へ各2回の移動完了。初期位置は数えません。
3. 地上用を接地中に2個、空中用をジャンプ中に2個取得。先に地上、次に空中を練習します。
4. goodゲージを0から満タンにして、種類1のデコレーションの配置完了を待ちます。
5. 減算アイテムを3個連続で回避。接触で0へ戻ります。後方へ通過した物だけを成功扱いにし、タイムアウト・片付けは数えません。
6. ジャンプ禁止で焦げを体験。焦げ演出・削除終了後に新しいパンケーキを配置し、ジャンプを解禁。10秒連続で焦がさなければ完了。失敗時は補充後に0秒から再開します。
7. 火事レーンに合計3秒接触後、10秒連続で回避。火事のコンロは開始時のレーンに固定します。焼きゲージは有効で、火事のレーンでは通常の10倍の速さで上昇します。焦げたら削除終了を待って新しいパンケーキを補充します。補充中は計測せず、接触時間は引き継ぎ、連続回避時間は0秒に戻します。回避中の火事接触でも0秒へ戻ります。

④ではアイテムゲージ、⑥・⑦では焼きゲージを黄色い点滅枠で強調します。説明表示中から練習終了まで表示し、次の説明へ進むと解除・切替します。シーンへの手動追加は不要です。

チュートリアル中にスコアが増減すると、スコア表示にも同じ黄色い点滅枠を2秒間表示します。連続で増減した場合は最後の変更から2秒まで延長します。ゲージの強調とは同時に表示でき、0点加算など値が変わらない場合は強調しません。表示時間はTutorialManagerのScore Highlight Secondsで調整できます。

火事の接触は、このゲームのコンロ仕様に合わせて「プレイヤーの実際のX座標が、火事レーン中心からFire Lane Radius以内」としています。初期値は0.8。上下のジャンプではなくレーン移動で回避します。

⑦の開始時は対象コンロの既存の警告マークを1秒間表示し、その後同じコンロで発火します。警告中に移動しても発火位置は変わりません。system_eventのCaution Objは左・中・右の3つすべてを設定してください（現在のTutorialシーンでは設定済み）。

## シーン / Prefab

- SpawnerのitemObj[0]はgood、[1]はbad。2つのspawnTransはワールドYの低い方を地上、高い方を空中として使用します。
- 地上/空中の高さ、アイテム速度、Fire Lane Radiusはプレイテストで調整してください。
- Place PrefabとTop Place Prefabは種類番号で参照します。TutorialシーンのTop Place Prefabを2要素に修正済みです。
- 表示用Prefabのsystem_visualObjsは無効にします。落下用だけを通知元として扱います。
- 通常のランダム出現、時間イベント、制限時間はチュートリアル中停止します。①〜⑤では焼きを停止し、⑥・⑦の練習中は有効にします。説明待ちと補充中は停止します。
- 位置マーカーやユーザーの既存の配置計算は維持しています。レッスン開始・焦げ再試行では練習用スタックをリセットします。
- 日本語UIはTutorial Fontに日本語対応TMP_FontAssetを指定できます。未指定ではWindowsのYu Gothic / Meiryoから実行時生成します。別環境へ配布するときは同梱可能な日本語フォントを明示的に設定してください。

## 検証

- `dotnet build Assembly-CSharp.csproj --no-restore --verbosity quiet`
- `pwsh -File Tests/Run-TutorialChecks.ps1` : 本番のTutorialProgressをコンパイルし、ジャンプ/レーン/取得区分/連続回避/タイマーリセット/火事接触の17条件を検証。
- Unityでの受け入れ確認: ①空中連打、②同一レーン保持、③取り逃しと再出現、④空のゲージでも強調枠が見えること・配置完了待ち、⑤2回回避後に接触して0、⑥ゲージ強調・焦げ後の再補充、⑦火事位置固定・ゲージ上昇・合計3秒接触・焦げ後の補充・9秒後の接触で0、完了後のInGame切替。
- 追加確認: タイマーと説明文が重ならないこと、最初のジャンプ直後の連打で再ジャンプせず着地後に再ジャンプできること、⑦の警告が1秒間表示されてから発火すること。物理接触と表示はUnityの再生で確認してください。
